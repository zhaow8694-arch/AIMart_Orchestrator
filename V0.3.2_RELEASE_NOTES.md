# V0.3.2 Release Notes

Version: v0.3.2
Release: Autonomous Runner Hardening

## Included

- Stable generated runner: `scripts/run-autonomous-version.ps1` and `.sh`.
- Stage machine: `scripts/runner-stage-machine.ps1` and `.sh`.
- Sample pack normalizer: `scripts/normalize-sample-pack.ps1` and `.sh`.
- Failure classifier: `scripts/classify-runner-failure.ps1` and `.sh`.
- Runner runtime files: `runtime/RUNNER_STATE.json`, `runtime/RUNNER_FAILURE_CLASSIFICATION.md`, `runtime/RUNNER_RECOVERY_POLICY.md`, `runtime/RUNNER_NEXT_ACTION.md`, and `runtime/RUNNER_FINAL_SUMMARY.md`.
- Completion gate checks for generated runner hardening files.
- Release dogfood evidence at `releases/v0.3.2/dogfood/RUNNER_HARDENING_VALIDATION.md`.

## Hardening Notes

- Autonomous Runner Hardening standardizes execution around the single current runner entry.
- Runner Self-Test runs the stage machine, generated validation scripts, sample normalization, and final gate checks.
- Failure Classifier covers pnpm argument loss, PowerShell syntax, Codex argument ordering, sample ZIP failures, dirty worktrees, and historical release modification.
- stale sample cleanup prevents old source or sample artifacts from satisfying a current run.
- ZIP magic / JSON zipBase64 handling supports both direct ZIP bytes and API-style JSON ZIP responses.
- normalized ZIP entry paths make Windows and Unix ZIP entry comparisons consistent.
- PowerShell 5.1 compatibility is preserved by avoiding unsupported syntax and brittle backtick-colon escaping.
- Completion Gate required before success keeps the runner from reporting PASS until validation gates complete.

## Compatibility

v0.3.1 customer launchers, lifecycle files, customer delivery verifier, and independent Codex/Claude Code/Trae/Cursor adapter generation remain supported.
