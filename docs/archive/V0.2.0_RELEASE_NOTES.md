# V0.2.0 Release Notes

## Scope

AIMart Orchestrator v0.2.0 is a Sandbox Autonomous Mode release for Codex-generated execution packs.

## New Features

- Execution mode selector with Supervised Mode default and Autonomous Mode option.
- Codex autonomous run profile in generated execution packs.
- Runtime SAFE_COMMANDS, DENIED_COMMANDS, and AUTONOMOUS_EXECUTION_POLICY files.
- Generated documentation for supervised start, autonomous start, logs, and APPROVAL_QUEUE handling.
- Clear UI and docs distinction between AIMart source release ZIPs and generated execution-pack ZIPs.

## Security Notes

Autonomous mode remains project-local. It does not use dangerous bypass/full-access mode, push to remotes, read secrets, deploy to production, run real database migrations, or mutate cloud resources.
