# V0.2.0 Implementation Report

## Scope

AIMart Orchestrator v0.2.0 adds the minimum viable Sandbox Autonomous Mode for generated Codex execution packs.

## Completed

- Added explicit Supervised Mode and Autonomous Mode execution mode handling.
- Added generated runtime command policy files: SAFE_COMMANDS, DENIED_COMMANDS, APPROVAL_QUEUE, and AUTONOMOUS_EXECUTION_POLICY.
- Added generated Codex autonomous prompt, autonomous runbook, and supervised/autonomous PowerShell and Bash launch scripts.
- Updated generated docs/README.md, docs/RUN_APP.md, and docs/SECURITY_AND_PERMISSIONS.md with Codex startup, logs, and approval queue handling.
- Updated UI copy to distinguish source release ZIPs from generated execution-pack ZIPs.

## Safety

Autonomous launch scripts use workspace-write with approval never. Supervised launch scripts use workspace-write with on-request approval. Generated docs forbid dangerous bypass/full-access modes, remote push, historical release deletion, secret reads, production deployment, real database migration, and cloud resource creation/deletion.

## Verification

- pnpm lint passed.
- pnpm test passed: 13 files, 41 tests.
- pnpm build was attempted and blocked by sandbox filesystem policy while Next.js tried to write build output.
- Release ZIP generation was blocked by the same external-process write policy.
- Local tag creation was attempted and blocked by Git ref lock permission denial.
