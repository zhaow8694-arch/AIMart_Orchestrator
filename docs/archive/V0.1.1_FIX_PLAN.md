# V0.1.1 Fix Plan

Date: 2026-06-10

## Goal

Ship v0.1.1 as a scoped patch release that resolves the v0.1 audit follow-ups without expanding the product scope.

## Scope

1. Fix the Web UI loading state so stale download links and summaries are not shown while a new pack is being generated.
2. Standardize "forbidden items" language across UI, generated docs, and adapter output.
3. Clearly distinguish the source release ZIP from generated execution pack ZIPs in delivery docs and release artifacts.
4. Correct FINAL_DELIVERY_CHECK wording so it refers to generated execution-pack docs.
5. Align release manifest wording with packaging exclusions and generated sample artifacts.
6. Require the Unix `zip` command during preflight instead of silently falling back to tar.gz for release packaging.
7. Update version metadata to 0.1.1.
8. Update tests, run lint/test/build, run finalize, and produce v0.1.1 release artifacts.

## Non-Scope

- No new target adapters.
- No cloud runner.
- No production deployment.
- No remote Git push.
- No UI redesign beyond the loading-state fix.

## Implementation Order

1. Add tests for the UI loading state, generated wording, script preflight behavior, and version metadata.
2. Implement the minimum code changes needed for those tests.
3. Update root scripts and delivery documents.
4. Run lint, test, and build.
5. Run the Windows finalize script.
6. Generate the v0.1.1 release folder with source release artifact and sample generated execution-pack artifact.

## Verification

- `pnpm.cmd run lint`
- `pnpm.cmd run test`
- `pnpm.cmd run build`
- `powershell -ExecutionPolicy Bypass -File .\scripts\finalize.ps1`
