# V0.2.0 Known Issues

No known P0 or P1 blockers are recorded in product code. The issues below are environment or delivery limitations observed in this sandbox.

| ID | Severity | Issue | Impact | Recommendation |
|---|---|---|---|---|
| KI-001 | High | External processes cannot create new workspace files in this sandbox. `pnpm build` reaches Next.js build startup but fails when Next attempts to write build trace/output files. | Final build verification cannot complete in this sandbox, even after redirecting build output away from the locked `.next` folder. | Rerun `pnpm build` in a local environment where Node processes can write project build artifacts. |
| KI-002 | High | Release ZIP creation is blocked by the same filesystem policy because PowerShell/Node child processes cannot write new files under `releases/v0.2.0`. | Source ZIP, sample generated execution-pack ZIP, SHA256.txt, and RELEASE_MANIFEST.txt could not be generated here. | Generate `releases/v0.2.0` artifacts after running verification in a writable local environment. |
| KI-003 | High | Local tag creation is blocked by Git ref lock permission denial for `.git/refs/tags/v0.2.0.lock`. | Local tag `v0.2.0` could not be created in this sandbox. | Create the local tag with `git tag v0.2.0` after moving to a writable Git checkout. |
