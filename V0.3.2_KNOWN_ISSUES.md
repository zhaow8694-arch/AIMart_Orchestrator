# V0.3.2 Known Issues

Version: v0.3.2
Release: Autonomous Runner Hardening

No known product-code P0 or P1 issues are recorded before final verification.

## Verified Risk Areas

- Autonomous Runner Hardening keeps execution on the single current runner entry and blocks old V1/V2/V3/V4/V5/V6/V7/V8/V9 hotfix runners.
- Runner Self-Test is required to exercise runner state, validation scripts, sample normalization, and final gate behavior.
- Failure Classifier output should be reviewed before opening blocker or known-issue entries.
- stale sample cleanup prevents outdated sample packs from being accepted as current artifacts.
- ZIP magic / JSON zipBase64 handling distinguishes real ZIP files from API JSON responses and invalid text/HTML responses.
- normalized ZIP entry paths reduce false failures caused by Windows backslashes in ZIP entries.
- PowerShell 5.1 compatibility remains a watch item for generated runner templates and checked-in `.ps1` scripts.
- Completion Gate required before success remains the acceptance rule for any autonomous run.
